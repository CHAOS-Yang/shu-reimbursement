# templates — 校方模板不随本仓库分发

## 为什么不内置

《上海大学国内差旅费报销单》《出差审批单》等空白表格的著作权归学校，且**每次办法修订都可能换版**。
把某一版 xlsx 塞进开源仓库，只会让后来者拿到过期表格。

正确做法：**从财务处官网取当期版本**，或直接让老师在财务系统里下载。

## 怎么取

财务处：<https://cwc.shu.edu.cn/> → 下载专区 / 办事指南 → 「国内差旅」条目。

**附件有防盗链**，裸 `curl` 取回的是验证码 HTML。用这个流程：

```bash
# 1) 访问详情页，落 cookie
curl -sS -c cookie.txt -A "Mozilla/5.0" "<详情页URL>" -o page.html

# 2) 找附件直链
grep -oE 'href="[^"]*download\.jsp[^"]*"' page.html

# 3) 带 cookie + Referer 下载
curl -sS -b cookie.txt -e "<详情页URL>" -A "Mozilla/5.0" "<附件直链>" -o 模板.xlsx
file 模板.xlsx        # 应显示 Microsoft Excel 2007+
```

## 需要的模板清单

| 文件 | 用途 | 关键点 |
|------|------|--------|
| 国内差旅费报销单及出差审批单（**2026 版**） | 差旅 | 19 行 × 17 列；审批单 6 列、序号 1–8；`D V L` 卡用 J3「二级及以上教授（科研经费）」档 |
| 劳务费支取表（2025 版） | 劳务 | `.xls` 含签名图，**禁止程序化修改** |
| 市内公共交通费结算单 | 市内交通 | 选「凭票据实」时用 |
| 会议审批表（非科研 / 科研） | 会议 | 一事一批，附会议通知与议程 |
| 专家咨询意见表 + 税前对照表 | 专家咨询费 | 配套使用 |
| 租车说明 | 租车 | 租车视同城市间交通费的必要附件 |
| 校外人员来访承诺书 | 邀请来访 | 不计发伙食补助 |

## 拿到模板后的第一件事

```bash
python scripts/patch_xlsx.py 模板.xlsx --show
```

确认：

1. sheet 名字与 `references/04`、`references/05` 里写的一致；
2. 列宽 / 行高的默认值（2026 版报销单：`O≈7.4`、`L≈6.1` 偏窄，需要调到 `O=12`、`L=8.2`）；
3. 有没有 `xl/media/*`（签名图）。空白模板**没有**，复制出来的表也没有 → 见 `references/07` §5。

如果 sheet 名或坐标变了，说明学校换了版式，先更新 `references/` 再填表。
