# 09 · 日常报销（非差旅）：科目口径

差旅单只装四类费用（城市间交通、住宿、伙食补助、市内交通）+ 会务/手续费/保险。
**其余一律走日常报销**，选对费用类别比发票好看更重要。

## 1. ★办公费 vs 材料费（最常错）

| 类别 | 适用 |
|------|------|
| **办公费** | **不符合固定资产标准的日常办公用品**、书报杂志、办公软件（会员 ≤1 年）、**电脑配件/耗材** |
| **材料费** | **专用材料**、实验室耗材、试剂、实验用低值品 |

判据来自百问百答与《公务卡强制结算目录》：看**用途是「办公」还是「专用材料」**，不是看东西值多少钱。

### 一个真实的退单案例的教训

「刻录光盘 + 外置光驱」到底走哪个科目？

- 它们**不是专用材料** → 属**办公用品 / 电脑配件** → 应走 **办公费**。
- 走材料费会被退，理由就四个字：**「需走办公」**。
- ⚠ 但如果该经费卡**根本没有办公费科目额度**，就只能：① 改走「材料费」并**附情况说明**；② 换一张有办公费额度的卡。先查预算科目再提交。

## 2. 办公费的具体要求

1. 发票须注明**名称、数量、单价**。
2. 明细清单：
   - 发票开「**电器电子产品及配件**」且**≥500 元** → 需明细清单；
   - 发票开「**通讯器材及配件**」「**数码产品及配件**」→ **不论金额**都要清单。
3. 办公软件会员费：**≤1 年**。
4. **400（含）–1000（不含）元的低值两用物资**，仅限以下 **10 类**须走资产平台入库：
   打印机、扫描仪、显示器、电视机、冰箱、洗衣机、饮水机、微波炉、吸尘器、取暖(冷)电器。
   → **光驱不在 10 类内，不需要入库**（别被"电子产品"吓到）。
5. 单笔 **≥2 万** 须走采购招标流程；2–10 万自行采购、原则选入围供应商。

## 3. 支付记录规则

- **支付记录不论金额都要**（这是日常报销与差旅的区别）。
- **<500 元不强制公务卡**，可用个人支付 + 截图。
- 电子发票**必须上传源文件**（pdf/ofd）。

## 4. ★包干制经费的负面清单（容易违规）

上海市财政科研项目「**包干制**」试点（市科委《进一步完善上海市财政科研项目经费"包干制"试点方案》）负面清单**明确不得列支办公设备和材料费用**。

→ 办公用品 / 材料费走**市财政包干卡＝违规**。区分三种包干：

| 类型 | 能否列支办公/材料费 |
|------|---------------------|
| 市财政「包干制」试点 | **禁止** |
| 横向 / 校级人才包干 | 按合同，一般可 |
| 国自然类包干 | 不编预算，但仍受「与项目相关」约束 |

## 5. ★会费 / 学会会员费（高频误操作）

参会时常顺带缴的**学会会费（个人会员年费）不能放进差旅单**。

- **票据本身合规**：《全国性社会团体会费统一票据（电子）》是**财政部监制的财政票据**（《财政票据管理办法》财政部令第 70 号 第六条第（三）项第 3 目），交款人常为单位名称，**可作为报销凭证** —— 不要误判为废票。
- **问题在科目**：127号第三条定义差旅费仅含四类费用；第二十三条会议/培训可报往返交通 + 住宿 + 注册（会务）费 + 培训费。**会费不在其中**；报销单「其他费用」也只有会务费/注册费、购票手续费、保险费三栏。塞进去＝**超范围列支**。
- **正确途径（推荐顺序）**：
  1. **单独走「日常报销」**（不要选「国内差旅」），费用类别选 **学术活动费 / 学会会费 / 科研业务费—其他**，附会费票据 + 支付记录（前提：该卡预算有对应科目额度）；
  2. 走学院公用经费的学术活动费 / 学科建设费；
  3. 走横向经费（使用较灵活）；
  4. 请学会把会费与注册费合并开票 —— **财政票据与增值税发票不得串用**，实操基本不可行，仅备选；
  5. 自付（会员权益归个人时属常见处理）。
- **识别要点**：票据标题含「社会团体会费统一票据」、项目名称「会费」→ 一律按本条处理。

## 6. 退单整改的标准路径

收到退回意见后，按这个顺序改，一次到位：

```
1. 改费用类别（如 材料费 → 办公费）
2. 补明细清单 / 订单截图
3. 补支付记录
4. 加情况说明（写清用途、单价低于固定资产与低值耐耗品标准）
5. 重新提交
```

**情况说明怎么写**：一句话讲清「这是什么、干什么用、为什么不入固定资产」。
例：*「外置光驱单价 XXX 元，用于读取历史归档光盘，未达固定资产标准，亦不属低值耐耗品 10 类范围，申请按办公费列支。」*

## 7. 禁止报销

月饼、礼品、健身、美容、充值卡等个人消费；与业务无关的支出。
