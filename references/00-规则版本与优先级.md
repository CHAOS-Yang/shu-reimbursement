## 4. 从官网抓规则的姿势（含防盗链）

财务处的附件直链走 `download.jsp`，**有防盗链**：裸 `curl` 取回来的是验证码 HTML，不是 PDF。

```bash
# 1) 先访问详情页拿 cookie
curl -sS -c cookie.txt -A "Mozilla/5.0" "<详情页URL>" -o page.html

# 2) 从详情页提取附件直链
grep -oE 'href="[^"]*download\.jsp[^"]*"' page.html | head

# 3) 带 cookie + Referer 再取
curl -sS -b cookie.txt -e "<详情页URL>" -A "Mozilla/5.0" \
     "<附件直链>" -o 规则文件.pdf
file 规则文件.pdf       # 必须显示 PDF document
```

**每年核对一次**：财务处通常在下半年更新办法与模板。判断方法——比较抓到的文件 `A1` 标题里的版本号（如「（2026版）」）与本仓库记录是否一致。

## 5. 2026 相对 2019 的实质变化（填表前必读）

| 项 | 2019 旧规 | 2026 新规 |
|----|-----------|-----------|
| 第一步 | 直接填表 | **先判经费卡类型**：`D V L` 走科研办法 |
| 住宿标准 | 科研 500–600 / 非科研 400–500 | **按省市分档**，非科研 400–650、科研 500–1300 |
| 市内交通 | 80 元/天包干 | **包干 与 凭票据实 二选一** |
| 会议培训补助 | 只在途期间 | 增加「统一安排但**食宿自理** → 按自然天数」分支 |
| 天数限制 | 无明确 | 公用经费外省市同一城市 **≤3 天**（科研无） |
| 交通工具 | — | **不得购超级经济舱、优选一等座**（紧急公务需分管校领导批） |
| 机票比价 | — | 低价票须附**同时刻同航班舱位价格截图** |
