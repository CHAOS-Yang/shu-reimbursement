# 03 · 差旅：特殊情形

## 1. 租车 / 自驾

| 情形 | 城市间交通费 | 伙食补助费 | 市内交通费 |
|------|--------------|------------|------------|
| 租车（**须审批说明**） | 视同城市间交通费，凭发票/清单/合同报销 | 凭住宿发票领取 | **不再领取** |
| 自驾（非科研） | 汽油费、通行费**不予报销** | 凭住宿发票领取 | 领取 |
| 自驾（科研·横向） | 汽油费、通行费可凭据**实报** | 凭住宿发票领取 | **不再领取** |
| 自驾（科研·纵向） | 汽油费、通行费**不予报销** | 凭住宿发票领取 | 领取 |

> 判据：自驾的油费/通行费是否报，看经费是**横向还是纵向**；市内交通是否领，看**有没有走「视同城市间交通费」这条路**——两者互斥。
> 租车需附《租车说明》（模板由财务处提供）。

## 2. 邀请校外人员来访

- 可按**职务或职称**选标准，凭票报销其**城市间交通费 + 住宿费**。
- 往返驻地和机场（车站、码头）**当天**的市内交通费据实报销。
- ★**不计发伙食补助费**。
- 须提供《**校外人员来访承诺书**》，一事一报。

## 3. 禁止出差的风景名胜区（21 处）

八达岭-十三陵、承德避暑山庄外八庙、五台山、太湖、普陀山、黄山、九华山、武夷山、庐山、泰山、嵩山、武当山、武陵源(张家界)、白云山、桂林漓江、三亚热带海滨、峨眉山-乐山大佛、九寨沟-黄龙、黄果树、西双版纳、华山。

> 事业单位在**党中央国务院明令禁止召开会议的风景名胜区**出差/开会，属违规。
> 若目的地城市本身在这些区域附近（如黄山、张家界），须在事由里写明具体调研内容并提供支撑材料。

## 4. 法定节假日 / 寒暑假 / 其他

审批单有勾选框：`□法定节假日 □寒暑假 □其他`。

- 在这三类时间出差 → 审批单**须填写完整充分的出差事由、调研内容或提供支撑材料**。
- 实操习惯：跨周末的行程勾「其他」；8 月出差勾「寒暑假」。
- 勾选手法（Wingdings 2 打勾）见 `05-表格-审批单坐标.md`。

## 5. 本市因公外出

- 本市区域内因公外出**一般不安排住宿**。
- 确需住宿须**经批准**，参照差旅办法报销住宿费和伙食补助费，**伙食补助费按住宿天数计算**。
- 科研：市区内确需住宿 → 报经**项目负责人**批准。

## 6. 行程闭环检查（填表前必做）

一条完整行程应该首尾闭合：

```
出发地 → 中转地 → 目的地 → …… → 返回出发地
```

- 缺回程 → 要么补票，要么在情况说明栏写理由（如「回程由对方单位安排车辆」）。
- 中间跳站（如 A→B→C 但只有 A→B 和 B→C 的票、没有 C→A）→ 同上。
- 改签/退票要做闭环校验：`原付金额 = 退款金额 + 退票费 + 改签票金额`，三项不全就追问用户。**去程和回程分开算。**
