# 08 · 因公出国（境）报销

> ★ **出国（境）不适用 127/128 号**，走另一套：PIM 审批 + 外汇柜台核销 + 智能报销制单。

## 1. 两条线，别只走一条

```
线 A · PIM          出访审批 + 经费核定  ──► 拿到批件与核定汇率
线 B · 智能报销      实际出账（做报销单）──► 钱才到账
```

**PIM 审完 ≠ 钱已报。** 很多人卡在这里。

### 线 A · PIM

入口：财务处首页「友情链接 → **PIM 流程**」→ 个人中心 → 国际交流合作 → **出国境总结及报销**
（或「因公出国(境)一站式服务平台」→ 业务申请）。

> ⚠ 首页的「智能报销 / 网上报销」是**日常报销**，出国境**不走那里**。
> 团组流水号在「**已结束事宜**」查；批件在「一站式」平台下载。

流程：行程表 → 出国小结 → 学院审核 → 专管员确认 → 国际部审核 → 换汇核定 → 财务处审核 → **携材料至外汇柜台**。

- ★**换汇表不是可下载的表格**（下载专区没有）。它是 PIM 流程里「国际部审核 → 财务处审核」之间的一个**节点**，已随财务处审核走过 → 去「已结束事宜」本团组记录里查**核定汇率**。
- ★**柜照硬前提**：因公证照须在**回国之日起 5 个工作日内**交还国际部（一站式服务中心 3 楼）。**未归还者不予办理报销。**

### 线 B · 智能报销（4 步）

1. **票据归集**（发票夹）
2. 填报预审
3. 线上审批
4. **财务审核制单**（财务打印发票与附件、生成凭证）

入口：财务处首页 → 自助服务 → 申报类 → **智能报销**；手机端：企业微信 → 智能财务。

⚠ **不要选「外币业务」入口**——那个的附件提示是「外币**版面费**」清单（论文版面费说明 / 中英文录取通知 / 外文发票 / 付款记录）。
出国（境）请走「**日常报销**」+ 国际合作与交流费。

外币口径：**先在财务大厅外汇柜台核算成人民币，再做报销单**。
估算汇率按**现钞卖出价**（如中行牌价 EUR 100 : CNY 7xx.xx）。

★ 支付信息「**谁支付进谁卡**」——代付、合住的份额要另附分摊说明。

## 2. 时限与前提

| 项 | 要求 |
|----|------|
| 事前审批 | 《上海大学出国、赴港澳任务批件》**原件**（事后补办通常不受理）+ 《因公出国或赴港澳台申请表》 |
| 报销时限 | **回国后 15 天内** |
| 核销方式 | 一份批件**一次核销，不可分批** |
| 外文凭证 | 须**中文注明开支内容 / 日期 / 数量 / 金额 + 经办人签字** |

## 3. 材料清单（官方口径）

**证明文件**

1. 《**上海市政府任务批件**》**原件** + 申请表
2. 公务护照信息页复印件 + **出入境记录页**
   - ★人工通道有**验讫章**则免；电子/自助通关无章才需打印出入境记录

**费用凭证 7 项**

| # | 项目 | 要什么 |
|---|------|--------|
| 1 | 机票 | 行程单（**公务机票**）+ **公务卡消费记录**；非国内航司须国际部审签《乘坐非国内航空公司航班和改变中转地审批表》；★跨国/跨城市机票**须出国前订联程**，国外期间购买不报销 |
| 2 | 签证费 | 外事服务中心或使领馆发票 |
| 3 | 保险 | **发票 + 保单**（两件，缺一不可） |
| 4 | 住宿 | ★**国外酒店开具、外汇结算**、带 **INVOICE / RECEIPT** 字样 |
| 5 | 注册费 | **注册费通知函 + 发票**；参会须**邀请信**（外文附中文翻译） |
| 6 | 城市间交通 | 发票 + 出国前国际部批准；限**列车 / 长途巴士**，**不可租车** |
| 7 | 其他 | 带学生团须附培训合同 |

## 4. 补助标准（按《出国境报销标准字典表》）

按**城市**分档，单位 €/人·天，三项分别为「住宿 / 伙食 / 公杂」。示例：

| 城市 | 住宿 | 伙食 | 公杂 |
|------|------|------|------|
| 柏林、汉堡 | 150 | 60 | 38 |
| 慕尼黑 | 170 | 60 | 38 |
| 法兰克福 | 180 | 60 | 38 |
| 其他城市 | 120 | 60 | 38 |

- 伙食按**实际在外天数**计，减去对方供餐天数（可能算出 8.6 天这种非整数）。
- 公杂按**自然天数**计。
- 具体城市标准查字典表，别按国家套。

## 5. ★实操坑（都验证过）

### 5.1 住宿凭证：民宿是高风险项

官方要求「**国外酒店开具、外汇结算、带 INVOICE/RECEIPT 字样**」。

- **民宿 / Airbnb 天然不符前两条**，属**口径问题**，须备替代材料并**提前问财务处**，不要自己拍板。
- 但别急着下「开不出收据」的结论——**Airbnb 有正式收据**：文件名常为「住宿账单.pdf」，含 "Your receipt from Airbnb" + Receipt ID。获取途径：① 微信/邮件里的「住宿账单」附件（最常见）② App/网页行程页「获取收据」③ 客服补开。
- Airbnb 收据的 `Traveler` 栏**只写下单人的名字** → 靠**行程单（列全部入住人）+ 分摊与代付说明**佐证。
- 收据支付栏常只写 `Alipay` → 必须补**银行侧截图**，且要**实测支付链**（例：Airbnb → 支付宝 → 某张个人信用卡，而不是公务卡）。不要按默认假设填。

### 5.2 合住必须分摊

限额是「**每人每天**」，2 人合住**不能整笔全报**。

例：订单 ¥9,731.11，2 人 7 晚 → 每人份额 ¥4,865.56（核定时可能取 ¥4,865.55，**以核定数为准**）。

### 5.3 同行人代付

非本人刷卡 → 除支付记录外**必须附《分摊与代付说明》**，写清：房源、确认号、晚数、总额、代付人、**本人份额**、签字。

### 5.4 一单可能混用公务卡与非公务卡

- **机票 = 公务卡（硬性）**；
- 其余**外币交易公务卡往往不能结算** → 用个人卡支付后补**对账单**或**签字的情况说明**。

### 5.5 德铁等票据：Rechnung ≠ 乘车凭证

DB 的 `Rechnung`（发票）票面常写 "…berechtigt nicht zur Fahrt"（**不作为乘车凭证**）→ 需另附 `Fahrkarte`（车票）。
境外票据**抬头可以开学校**：`Shanghai University / <姓名> / 99 Shangda Road, 200444 Baoshan`。

### 5.6 「注册费收费标准」类材料

财务常要求证明**计费依据**（不只是发票）。官网费率表**通常没有 PDF**：

1. `requests` + `bs4` 抓 HTML 费率表；
2. `reportlab` 还原 A4（来源 URL + 访问日期 + 高亮本次档位）；
3. 加一页中文标注（开支内容 / 类别 / 档位 / 日期 / 数量 / 金额 / 凭证关联 + 签字栏）；
4. **原始 HTML 同目录存档**作凭证源。

**对账两步**：① 实付须**精确落在某一档**（会员/非会员 × Early/Late/OnSite）；② 用**缴费日期落在哪个时段**证明档位。

### 5.7 PIM 导出的 PDF 常名「生成.pdf」

批量导出后文件名全是 `生成.pdf`，散落在同一目录 → 先 `pdftotext -layout` 看内容再归位。

### 5.8 未成行怎么办

签证未出、行程取消但已产生费用 → 只报**已实际发生的费用**（通常是签证费 + 注册费），
出国小结按「**未成行口径**」写：说明原定行程、取消原因、未发生任何境外费用。
注册费若已过退费截止日，附上「不可退」的证明（费率表/条款截图）。
