# 04 · 《上海大学国内差旅费报销单》填表坐标

**19 行 × 17 列。** 2019 版与 2026 版单元格布局**完全一致**，只有两处不同：

| 位置 | 2019 版 | 2026 版 |
|------|---------|---------|
| A1 标题 | 上海大学国内差旅费报销单（2019版） | （2026版） |
| J3 人员级别 | 二级及以上教授 | 二级及以上教授**（科研经费）** |

> 所以下面这套坐标两版通用。**审批单不一样**，见 `05`。

## 1. 版面分区

| 区域 | 列 | 内容 |
|------|----|------|
| 城市间交通费明细 | A–H | A/B=出发**月/日**，C=出发地，D/E=到达**月/日**，F/G=到达地（合并），**H=金额** |
| 伙食/市内交通/住宿 | I–O | I=项目名、J:K=标准限额（合并）、L=人数、M:N=天数（合并）、**O=金额** |
| 其他费用 | P–Q | P=内容、Q=金额 |

## 2. ★交通行与补助行共用行号（最大的坑）

同一个行号既是第 N 程交通，又是某项补助：

| 行 | 交通（A–H） | 补助（I–O） |
|----|-------------|-------------|
| Row 6 | 第 1 程 | **I6 = 伙食补助费** |
| Row 7 | 第 2 程 | **I7 = 市内交通费** |
| Row 8 | 第 3 程（如有） | **I8:I11 合并 = 住宿费** |
| Row 11 | — | L11 = 发票金额 / O11 = 标准计算额 |

- 住宿费固定占 `I8:I11` 合并区。
- 超过 3 程时继续往下占行，但注意别把住宿区挤掉——住宿条目的地址是固定的。

## 3. 条目填法

模板条目**只填值，不删不改名**：

| 条目 | 填什么 | 备注 |
|------|--------|------|
| 伙食补助费 | 标准 × 人数 × 天数（`O6`） | 金额先用公式，写入前手动求值 |
| 市内交通费 | 标准 × 人数 × 天数（`O7`） | 同上 |
| 住宿费 | 实际住宿金额 / 本人份额（`O8`） | 不超限额 |
| 保险费 | 留空或按实 | 每人次可购 1 份 |
| 改期费 | 退票/改签手续费 | — |
| 退票费 | 留空 | 与改期费不同，改签用「改期费」 |
| **车站打车** | **永远留空** | 学校不报销此项 |

- 退款、酒店杂费、会员费、会费**不写入本单**。
- 行程必须闭环（见 `03-差旅-特殊情形.md` §6）。

## 4. 小计公式（Row 12）

| 格 | 内容 |
|----|------|
| **H12** | 交通小计 = `=H6+H7`（多程继续 `+H8+H9…`） |
| **O12** | 补助/住宿小计 = **`=O6+O7+O8`** ★绝不能只写 `=O8` |
| **Q12** | 其他费用小计（**值写在 Q12，标签在 P12**） |
| H13 | 合计金额（大写） |
| A13 | 合计金额（小写） |

## 5. 其他费用三栏

| 格 | 内容 |
|----|------|
| P7 / Q7 | 会务费、注册费 |
| P8 / Q8 | 购票手续费 |
| P9 / Q9 | 保险费 |

- **会务费/注册费要同时填 `Q7`（行项）和 `Q12`（小计）**，两处数值一致，方便财务看出构成。
- ★**会费/学会会员费不能放这里**（超范围列支），单独走日常报销，见 `09-日常报销-科目口径.md`。

## 6. 住宿费对比行（Row 11）

| 格 | 内容 |
|----|------|
| L11 | 发票金额 |
| O11 | 标准计算额 = 标准限额(J8) × 人数(L8) × 天数(M8) |

`L11 > O11` → 超限额，需出情况说明。

## 7. 合计金额大写（H13）

格式：`合 计 金 额 （大写）：           X 万 X 仟 X 佰 X 拾 X 元 X 角 X 分`

- 数字**逐个填入空白位**，不要写进括号里、不要另起一行。
- 万位没有则填 `零`。
- 大写必须与公式结果**完全一致**。

```
2563.36  →  零 万 贰 仟 伍 佰 陆 拾 叁 元 叁 角 陆 分
```

## 8. 取 sheet 的方式

2026 版模板的 sheet 顺序是：

```
1. 上海大学国内出差审批单     ← 在前
2. 上海大学国内差旅费报销单   ← 在后
```

**与 2019 版相反**。一律按名字取：

```python
wb = load_workbook(path)
ws = wb['上海大学国内差旅费报销单']    # ✅
ws = wb.worksheets[1]                  # ❌ 换版本就错
```

两个 sheet 都要检查：审批单常已由用户填好，报销单多为空白。
