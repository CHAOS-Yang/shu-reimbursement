# 11 · 实操坑清单

开工前扫一遍。每一条都对应一次真实的返工。

## 1. ★错版表格（最高频）

出差文件夹里的 `差旅_YYYYMM地点.xlsx` **可能是从别的出差文件夹直接复制来的**——文件名对了，内容还是上一次的行程和经费卡。

**必做**：逐格核对 出差人 / 日期 / 出发到达地 / 经费账号 是否与本次一致。

处置：备份为 `xxx.xlsx.bak_<原出差名>错版` → 用本次真实数据重填。

## 2. ★写表前先看有没有 `~$xxx.xlsx`

目录里出现 `~$xxx.xlsx` 说明**用户正用 Excel/WPS 打开该文件**。

此时 openpyxl 写入**会成功**，但用户在 Excel 里一保存，就用手里的旧版本**覆盖**掉你填的内容（真实事故：整页报销单被清空）。

处置三步：
1. 发现锁文件 → **先提醒用户关闭**；
2. 写完后**重新读一遍**校验关键单元格；
3. 交付前若发现被覆盖 → 从 `提交包/` 或 `存档/` 的副本恢复重填（保留用户自己改的部分，如审批单日期）。

## 3. 备份与命名

- 改任何 Excel 前 `cp x.xlsx x.xlsx.bak`。
- 暂存文件处理后保留到 `截图暂存/_备份/`；找不到文件先去备份找，别让用户重发。
- 用户文件夹里已有的 `.xlsx` **直接覆盖修改**（不生成新文件），改前备份即可。
- 命名格式：`差旅_YYYYMM地点.xlsx`，如 `差旅_202610成都.xlsx`。文件名叫错必须重命名。

## 4. OCR 与截图

- 大图先缩到 **1200px** 再 OCR。
- 支付记录截图常见形态：银行信用卡交易通知。
- OCR 可能误读商户名 → 匹配时**金额 + 日期为主，商户名仅参考**。
- 同一金额同日期的记录出现在多张截图里 → 只保留一份。

## 5. 支付立减

银行常有「立减」，实付 < 发票金额。

匹配策略：**金额差 < 2% 且同日期** → 自动绑定，备注差额。

## 6. 改签 / 退票闭环

```
原付金额 = 退款金额 + 退票费 + 改签票金额
```

三项不全 → 追问用户。**去程和回程分开算。**

## 7. 公务机票 GP 单号

- 单号格式 `GP` + 数字，通常在发票**左上角小字区**。
- 大尺寸 PDF/PNG 因压缩可能一次看不清全貌 → **先裁切放大顶部区域**再确认，别急着判定非公务机票。
- **两程都要查**：去程有 GP 不代表回程也有。

## 8. 同批次多文件夹

连续处理多组报销时，**出差人 / 出差事由 / 经费账号默认沿用上一次**的值。用户可能只给部分信息，不确定就快速确认一次。

但**经费卡不要盲沿用**——同一位老师不同行程可能换卡（`N` 卡 / `D` 卡交替）。卡号一律以当次审批单为准。

📦 提交包 → 🔵 进行中 → ⚠️ 待补材料 → ✅ 已提交 / 已报销

## 10. ★给境外/外文凭证加中文标注

财务要求外文凭证**用中文注明开支内容、日期、数量、金额并签字**。

### 正确做法：原凭证叠层（体积小、文字层可搜索）

1. `shutil.copyfile(原件, 目标)` —— **保住原对象流**（直接"打开另存"会重压缩图像）；
2. 用 **reportlab** 画一张同尺寸透明叠层（`pagesize` 取原页尺寸），字体用
   `TTFont("AU", "/System/Library/Fonts/Supplemental/Arial Unicode.ttf")`
   —— **reportlab 会自动子集化**，只嵌入用到的字形；
3. `pymupdf` 打开目标 → `page.show_pdf_page(page.rect, overlay, 0)` → `doc.saveIncr()`。

实测：收据 52 KB → **114 KB**，行程单 77 KB → **134 KB**，原件图像一个字节没动。

### ❌ 别用的做法

- **PyMuPDF `insert_font` / `TextWriter` 加中文** → 会**整包嵌入**字体（Arial Unicode.ttf ≈ 23 MB）→ 输出 14.6 MB / 22.8 MB，**超智能报销单件 10 MB 上限**，`saveIncr` 也救不了。
- PyMuPDF 三个连环坑：
  - `save(原路径)` → `ValueError: save to original must be incremental`
  - `subset_fonts()` 之后再存 → **插入的文字被子集化吞掉**
  - `add_redact_annot` 后不补字 → 残留 `\x00` 空字符块

### 折行必须自己量

- 用 `pymupdf.Font(...).text_length(s, size)` 或 `pdfmetrics.stringWidth()` **逐字符**测量累加。
- ⚠ **不要**用 `get_textbox(...).count("\n")` 判断行数：单行文本 `count == 0` → y 不推进 → 文字叠在一起。
- 原凭证已经满页 → **另加一页**放中文说明，不要压缩原凭证内容。

## 11. 生成中文公文/说明文档

```python
from reportlab.pdfbase.ttfonts import TTFont
TTFont('Songti', '/System/Library/Fonts/Supplemental/Songti.ttc', subfontIndex=6)
# 索引：0=SC-Black  1=SC-Bold  3=SC-Light  4=STSong  6=SC-Regular
```

- `ParagraphStyle(wordWrap="CJK", firstLineIndent=24, leading=24)`。
- ★`Paragraph` **只认 `<b>` 标签**，**不解析 `**加粗**` 这类 Markdown**——写进去会原样显示星号。

## 12. 一些工具判断

- `pdfinfo` 对部分 PDF（某些电子发票）**无输出** → 改用 `pdftotext -layout` 或 PyMuPDF 读。
- 判断底纹 / 裁切**必须采样像素**；`pdfplumber` 的单通道灰是字符串 `'0.851'` 而非 list。
- 文本层不受 `clipPath` 影响：被裁掉的字仍能 `extract_words()` 到。
