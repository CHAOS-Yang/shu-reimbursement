## 3. 经费账号的填法（两版通用）

- **标签格**写 `拟使用项目经费账号：`——**只保留标签**，不要把账号写在冒号后面。
- **值格**写实际账号，如 `N.14-GXXX-26-XXX`。
- 账号填在**右边格子里**（2026 版 C19 / 2019 版 C17），不并入标签文本。

模板设计逻辑是「标签在左列、值在右列」，与 A4「出差人姓名」/ C4 实际姓名一致。

## 4. ★复选框打勾（`□` → `☑`）

模板里是 `□`（U+25A1），通篇宋体。**不要替换成 `☑`/`√` 字符**——字体不含该字形，打印会变豆腐块或方框。

正确做法：用 **Wingdings 2** 字体渲染字母 `R`，视觉上就是「打勾的方框」。

```python
from openpyxl import load_workbook
from openpyxl.cell.rich_text import CellRichText, TextBlock
from openpyxl.cell.text import InlineFont

wb = load_workbook(path, rich_text=True)     # ★ rich_text=True 必须显式传
ws = wb['上海大学国内出差审批单']

FO = InlineFont(rFont='宋体', sz=14)                  # 普通文字
FG = InlineFont(rFont='Wingdings 2', sz=14)           # 复选框（写 'R' 即 ☑）
FU = InlineFont(rFont='宋体', sz=14, u='single')      # 下划线填空

ws['A16'].value = CellRichText([
    TextBlock(FO, '出差地区：'),
    TextBlock(FG, 'R'),            # ☑ 法定节假日
    TextBlock(FG, '\u00a0'),       # 复选框之间空一格
    TextBlock(FO, '法定节假日  '),
    TextBlock(FG, 'R'),            # ☑ 寒暑假
    TextBlock(FO, '寒暑假  '),
    TextBlock(FG, 'R'),            # ☑ 其他
    TextBlock(FO, '其他'),
])
```

**必踩的坑**：

1. ⚠ `load_workbook(..., rich_text=False)`（默认）会**抹平 run 级字体**——xlsx 里看到裸 `R`，用户打印出来却是 ☑。**必须传 `rich_text=True`**。
2. 复选框所在行用 `\n` 强制换行，别指望自动换行排得下。
3. 富文本 run 会被 Excel 当成一个整体，**不要在里面混公式**。

## 5. 日期保留「下划线填空」版式

模板把日期写成填空样式（`____年__月__日`）。填数字时用**带下划线的 run**，视觉上才是「填在横线上」：

```python
ws['A13'].value = CellRichText([
    TextBlock(FO, '出差时间：'),
    TextBlock(FU, '2026'), TextBlock(FO, ' 年 '),
    TextBlock(FU, '10 '),  TextBlock(FO, ' 月 '),
    TextBlock(FU, '20 '),  TextBlock(FO, ' 日  至  '),
    TextBlock(FU, '2026'), TextBlock(FO, ' 年 '),
    TextBlock(FU, '10 '),  TextBlock(FO, ' 月 '),
    TextBlock(FU, '23 '),  TextBlock(FO, ' 日'),
])
```

## 6. 换行与字号

- 长文本格（A14、A15）**显式设 `wrap_text=True`**，否则内容溢出到邻格或直接看不见。
- `A15:E18` 区域约容 **33 个 14pt 汉字/行**。超长的出差事由要**手工断行**（`\n`），不要靠自动换行猜。
- 行高要跟着放大，否则打印时下半截被裁。

## 7. 勾选判断

| 情况 | 勾 |
|------|-----|
| 跨周末的普通行程 | 其他 |
| 7–8 月（暑假）出差 | 寒暑假 |
| 春节/国庆等法定假日出行 | 法定节假日 |
| 目的地是 21 处禁止名胜之一 | 其他 + 事由写具体调研内容与支撑材料 |

允许多勾。

## 8. 审批权限对应

| 出差人 | 审批人 |
|--------|--------|
| 公用经费出差 | 经费负责人；经费负责人本人 → 所在学院(部门)负责人 |
| 项目经费 · 成员 | 项目负责人 |
| 项目经费 · 负责人 | 所在学院(部门)负责人 |
| 学院(部门)负责人 | 分管校领导 |

科研（128号）项目负责人可由**所在学院(部门)负责人或经授权的科研院长**审批。
